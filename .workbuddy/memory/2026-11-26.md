# 2026-11-26 21:34 — 第九阶段：集成终端

## 决策
- 用 **JNI forkpty**（NDK r27c）实现真 PTY；`script` 方案被否：toybox 没有该命令，Android 侧不可用。
- 终端内核自写 VT100/ANSI 子集（光标/擦除/SGR/备用屏幕/滚动区/DSR 应答），不引第三方终端库。
- 输入模型为「输入行 + 辅助键条」（用户确认）：Enter 发送整行，方向键/^C/^D/^L 等通过键条发送原始字节。
- 会话由 AppContainer 单例管理，最多 3 个，独立进程/PTY；离开界面不杀 shell。

## 实现
- `core/process/PtyNative`：JNI 封装 forkpty，返回 master fd + pid；resize 走 TIOCSWINSZ + SIGWINCH；waitpid 收尸；kill(-pid) 杀进程组。
- `data/terminal`：TerminalProcess（ParcelFileDescriptor + 流）、TerminalSession（读循环、50ms 快照节流、SIGTERM→SIGKILL、退出后关 fd）、TerminalSessionManager（环境选择、上限、配置）、TerminalPreferences（Properties 原子写）。
- `domain/terminal`：TerminalEmulator（UTF-8/CJK 宽字符、SGR 16/256/24bit 映射、CSI 子集、滚动回看 600 行）、TerminalLine、模型与按键字节。
- `feature/terminal`：Screen（顶栏/会话 chips/输出/键条/输入行/设置对话框）、ViewModel、TerminalOutput（AnnotatedString）、TerminalKeyBar、终端调色板（明暗两套）。
- 入口：文件管理器更多菜单、编辑器菜单、构建顶栏；路由 `terminal/{projectId}`。
- 构建：`ndkVersion = 27.2.12479018`、ndk-build、abiFilters 两个 ABI；AGENTS.md 增加原生构建约束。

## 验证
- assembleDebug / testDebugUnitTest / lintDebug 全绿；167 个 JVM 测试（新增 23：模拟器 16、偏好 4、按键 3）。
- APK 13MB，含 `lib/arm64-v8a/libmobileide-pty.so`（7.4KB）与 v7a；JNI 符号经 llvm-nm 核对。
- **未验证**：开发沙箱没有 `/dev/ptmx`，无法创建 PTY；没有真机/模拟器，交互式行为（bash、Ctrl+C、vim/top、proot 内 pty）全部未实跑。

## 已知限制
- 输入是行缓冲，shell 自身的行内编辑（readline）不被使用；全屏程序只能靠键条发控制序列。
- 应用进程被杀后，已启动的 shell 可能成为孤儿进程（未设 PR_SET_PDEATHSIG，避免误杀）。
- cwd 显示为会话启动目录，不跟随 OSC 7；未做命令历史记录（不落盘，避免敏感信息）。
