# 2026-11-27 04:10 — 真机问题修复（clangd 启动报错 / Python 无高亮 / 补全回归 / 终端 IME）

## 用户反馈（一加 13 / ColorOS 17）
1. clangd 启动日志报 unknown option（`--clangd-indexing-threads`，clangd 14 不认识）；`--background-index=0` 也改为 `=false`。
2. Python 文件无语法高亮：Sora 0.23.5 没有 Python 模块 → 新增 `domain/editor/PythonHighlighter.kt`（小型分词器：关键字/字符串/注释/数字/装饰器/函数名）+ `feature/editor/components/PythonLanguage.kt`（AnalyzeManager 直喂 span），`EditorTheme.kt` 加 `PYTHON -> PythonLanguage()` 分支。
3. C 文件补全在接入 LSP 后消失：`LspLanguage.requireAutoComplete` 之前从不调 delegate 且在阻塞 LSP 请求后触碰失效的 ContentReference（Sora 用户再打字即失效，异常会杀死补全线程）→ 修复顺序：先 delegate → 阻塞前快照 prefix → 发布前 `content.validateAccess()` 守卫，全部包 runCatching。
4. 终端点击空白不唤起输入法：焦点去了 AndroidView wrapper（无 InputConnection）→ `TerminalInputView.focusForInput()`（requestFocus + showSoftInput），`TerminalScreen` factory 存 view 引用 + setOnFocusChangeListener 同步焦点态。

## 编译坑（PythonLanguage 首次编译抓出）
- `EditorColorScheme` 的包路径是 `io.github.rosemoe.sora.widget.schemes`，不是 `io.github.rosemoe.sora.widget`。
- `textStyle` DSL 参数名是 `foreground`（javap LocalVariableTable 确认：foreground/background/bold/italic/strikethrough/noCompletion）。
- 实现 Java 接口时 Kotlin 会读 CLASS 级 `@Nullable/@NonNull` 注解：`setReceiver(@Nullable StyleReceiver)` → 实现 `receiver: StyleReceiver?`；`reset(@NonNull ContentReference, @NonNull Bundle)` → 实现 `extra: Bundle`（非空）。写反报 "overrides nothing"，报错信息不直观，靠 javap -v 看字节码注解定位。
- Sora 类解压参考：`/tmp/sora-aar/editor/classes.jar`（无 unzip，用 python3 zipfile）。

## 验证
- `assembleDebug / testDebugUnitTest / lintDebug` 全绿（8m57s），219 测试通过，lint 0 error。SAF 仍为零。
