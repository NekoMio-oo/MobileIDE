# 已知问题

最后更新：2026-11-27（1.0.0）

## 1. 未验证项（最重要）

当前没有真机或模拟器，以下行为**只经过代码审查/单元测试，未做端到端验证**：

- APK 安装、启动、首屏渲染、深浅色视觉与不同屏幕尺寸布局。
- “所有文件访问”授权流程与厂商系统差异。
- Debian rootfs / PRoot 的下载、SHA-256 校验、解压、安装与卸载。
- apt 工具链安装（gcc、g++、OpenJDK、Go、Rust、Node.js、TypeScript）。
- 终端 PTY 启动、命令执行、Ctrl+C、多会话与进程退出。
- LSP 服务器启动、补全、诊断、悬停、跳转定义、查找引用。
- Git 初始化、提交、分支、Fetch/Pull/Push、HTTPS/SSH 凭据与网络错误处理。
- Android Keystore 加解密在真实设备上的行为。
- Activity 重建、进程被回收、后台限制、存储权限被撤销后的恢复。

## 2. 功能限制

| 问题 | 影响 | 说明 / 规避 |
| --- | --- | --- |
| PRoot 运行时仅 arm64 | `armeabi-v7a`、`x86_64` 设备无法使用运行环境 | 运行环境页面会显示不支持；请在 arm64 设备使用 |
| Kotlin 无工具链 | 不能编译 Kotlin 项目 | Debian 12 不提供 `kotlinc`；继续使用编辑器与 LSP 以外的功能 |
| LSP 仅 C/C++/Python/Java | Go/Rust/Kotlin/JS/TS/HTML/CSS 无语言服务器 | `lsp_catalog.properties` 中标记为 `unsupported` 并写明原因 |
| npm 安装通道未实现 | 依赖 npm 的 LSP（TS/HTML/CSS）不可用 | 后续阶段实现 |
| 语法高亮有限 | Go/Rust/HTML/CSS 为纯文本；C/C++/Kotlin/JS/TS 复用 Java 词法器 | Sora 0.23.5 仅内置 Java lexer；Python 为自定义扫描器 |
| HTML/CSS 无预览 | 只能编辑，不能运行/预览 | 未纳入当前版本范围 |
| 构建无 R8 | Release 包体积偏大 | 未做真机回归前不启用收缩 |
| 无 UI 自动化测试 | 导航、对话框、深浅色等依赖人工验证 | 仓库不含 `androidTest` |
| 未添加 LICENSE | 默认保留所有权利 | 需项目所有者确认许可证 |

## 3. 兼容性与分发

- `targetSdk = 28`：不满足 Google Play 当前要求；提高后会破坏 PRoot 的 `execve()` 能力。应用仅通过 GitHub/侧载分发。
- `MANAGE_EXTERNAL_STORAGE`：Android 11+ 必须手动授予；部分厂商系统会额外限制后台进程、安装未知应用或“所有文件访问”。
- Android 14+ 侧载 targetSdk 28 应用通常可行，但不同 ROM 可能有额外警告；未真机验证。
- 应用包含 `x86_64` 原生库，但本地 Debian 环境为 arm64，模拟器上运行时功能不可用。
- 分屏、折叠屏、横屏、字体缩放未做专门适配与验证。

## 4. 数据与稳定性

- 数据库迁移只做了代码审查与 JVM 层验证，未在真实旧版本数据上执行升级测试；迁移失败时没有自动备份/回滚 UI。
- 运行环境安装中断后，残留文件位于应用缓存，重新安装会重新下载校验；不保证断点续传。
- 构建日志单个文件上限 2 MB，超出后丢弃尾部旧内容；终端回滚缓冲有上限（设计如此，非缺陷）。
- 可编辑文件大小上限 2 MB；超过时编辑器拒绝打开并提示。
- 应用被系统回收时，正在运行的终端/构建/LSP 进程会结束；重新打开后任务显示为 `INTERRUPTED`，不会伪造成功状态。
- 卸载应用会删除运行环境与数据库，项目文件保留；用户需自行备份项目。
